# 附录A：Tommy Reilly年表

| 年份 | 事件 |
| 1919年8月21日 | 出生于加拿大安大略省圭尔夫市 |
| 1927年 | 开始小提琴学习（8岁） |
| 1930年 | 加入父亲创建的Elmdale口琴乐队 |
| 1932-1933年 | 连续获得加拿大国家展览会金奖 |
| 1935年 | 全家迁往英国 |
| 1937-1939年 | 与"The Four Phillips"欧洲巡演 |
| 1939年 | 进入莱比锡音乐学院；9月，被盖世太保逮捕 |
| 1939-1945年 | 战俘营囚禁，技术体系形成 |
| 1945年 | 返回英国，开始BBC广播生涯 |
| 1947年左右 | 开始在BBC广播中演出 |
| 1948年 | 在托基（Torquay）遇见Michael Spivakovsky，萌生协奏曲创作 |
| 1951年5月26日 | 首演Spivakovsky《口琴协奏曲》 |
| 1953年 | 斯图加特"轻音乐周"成功；奥斯陆《流浪者之歌》录音 |
| 1965年 | 发行爱尔兰民歌专辑《The Life of Reilly》（World Sound T 541） |
| 1966年 | 首演Farnon《前奏曲与舞曲》 |
| 1967年 | 与Hohner合作创造银口琴；创办Tommy Reilly国际俱乐部 |
| 1968年 | 发行《Colours of My Life》（Polydor 184 107） |
| 1969年 | 《午夜牛郎》主题曲；与James Moody合著教材出版 |
| 1971年 | Tommy Reilly国际俱乐部结束 |
| 1972年 | 发行法国风情专辑《Harmonica Parisien》（Polydor 2382 016） |
| 1976年 | 与Sigmund Groven发行双口琴专辑《Music for Two Harmonicas》 |
| 1987年 | 世界口琴锦标赛大师班 |
| 1992年 | 被授予大英帝国勋章（MBE） |
| 1993年12月 | 遭遇严重车祸，健康受损 |
| 1995年 | 韩国Classic People发行精选集《Tommy Reilly》（CPCD-07） |
| 1996年 | EMI Premier《Vintage Themes》收录其电视主题曲录音 |
| 1998年 | 最后一次专业大师班（达廷顿） |
| 2000年9月25日 | 逝世于英国萨里郡弗伦沙姆 |
| 2019年 | 《A Life in Music》专辑发行，百年诞辰纪念 |
