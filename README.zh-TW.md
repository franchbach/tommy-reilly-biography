# A Complete Book For Tommy Reilly（湯米·賴利全傳）

**湯米·賴利（Tommy Reilly, 1919–2000）——二十世紀最偉大的半音階口琴演奏家之一。本書是他的中文傳記（franchbach 著），並附機器翻譯英文初稿；德文、日文譯本規劃中。**

## 關於本書

Tommy Reilly 將口琴從街頭樂器提升到古典音樂獨奏舞臺。在他長達六十餘年的藝術生涯中，超過三十位作曲家——包括 Gordon Jacob、Robert Farnon、James Moody 和 George Martin——為他創作作品。本書涵蓋：

- 早年歲月：從加拿大到英國（1919–1939）
- 戰俘營歲月（1939–1945）
- 戰後重建：技法科學與演奏風格的奠基（1945–1951）
- 突破與認可：第一首口琴協奏曲與音樂分析（1951）
- 黃金年代：委託創作與作品深度解析（1951–1970）
- 銀口琴的誕生：樂器革新與製造工藝（1967）
- 薪火相傳：口琴教育奠基與傳承（TRIC 國際口琴俱樂部）
- 錄音、演出與跨界合作
- 主要唱片目錄與研究
- 二十世紀口琴藝術地圖：Reilly 與他的同時代人
- 附錄 A–G：年表、委託作品列表、唱片目錄、參考文獻、語錄集、演出足跡、考據與存疑筆記
