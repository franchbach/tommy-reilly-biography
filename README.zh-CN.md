# A Complete Book For Tommy Reilly（汤米·赖利全传）

**汤米·赖利（Tommy Reilly, 1919–2000）——二十世纪最伟大的半音阶口琴演奏家之一。本书是他的中文传记（franchbach 著），并附机器翻译英文初稿；德文、日文译本规划中。**

## 关于本书

Tommy Reilly 将口琴从街头乐器提升到古典音乐独奏舞台。在他长达六十余年的艺术生涯中，超过三十位作曲家——包括 Gordon Jacob、Robert Farnon、James Moody 和 George Martin——为他创作作品。本书涵盖：

- 早年岁月：从加拿大到英国（1919–1939）
- 战俘营岁月（1939–1945）
- 战后重建：技法科学与演奏风格的奠基（1945–1951）
- 突破与认可：第一首口琴协奏曲与音乐分析（1951）
- 黄金年代：委托创作与作品深度解析（1951–1970）
- 银口琴的诞生：乐器革新与制造工艺（1967）
- 薪火相传：口琴教育奠基与传承（TRIC 国际口琴俱乐部）
- 录音、演出与跨界合作
- 主要唱片目录与研究
- 二十世纪口琴艺术地图：Reilly 与他的同时代人
- 附录 A–G：年表、委托作品列表、唱片目录、参考文献、语录集、演出足迹、考据与存疑笔记
